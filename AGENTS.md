# Инструкции для AI-агентов

Перед началом любой работы в этом репозитории полностью прочитай корневой файл
[`AI_Instruction.md`](AI_Instruction.md) и следуй ему. Это единый источник проектных правил.

Для задач, затрагивающих интерфейс, дополнительно прочитай
[`docs/ui-components.md`](docs/ui-components.md).

Если в целевом каталоге есть более конкретный `AGENTS.md`, прочитай и его. При противоречиях
не выбирай правило самостоятельно — сообщи владельцу проекта и запроси решение.
