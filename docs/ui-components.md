# Справочник стандартных блоков интерфейса

Версия 1.10 (2026-10-30): `PlanYearCalendar` — бледные дни соседних месяцев, одна разметка во всех режимах, наведение светло-серым, выбор — рамкой; `Page fit`; отступ слотов `Header` от края; выбранный период в маленьких календарях — рамкой. 1.9 (2026-10-29): меню «Плана» по годам в три яруса, `PlanYearCalendar` — сохранён для выбора дня; месяц использует `PlanMonthList`, а неделя и еженедельный план — общий `PlanWeekList`. 1.8: меню раздела «План» в два яруса, черта в `SideMenu`. 1.7: план недели — ячейки по 15 мин, перетаскивание, правка названия в карточке. 1.6: `InlineTitle`, `StatusList`; `Header` — слоты `#left` и `#right`, `HeaderLink`; номера в списках; `DaySlotPicker`; `SideMenu`; «Удалённые». Цель — собирать интерфейс из общих блоков, чтобы дизайн менялся
в одном месте. Перед тем как писать разметку, найдите здесь подходящий блок. Если подходящего нет —
сначала обсудить и добавить общий блок (и строку сюда), потом использовать.

Состояние: справочник составлен по коду; часть страниц пока не следует ему полностью — это задачи
унификации (раздел «Известные отступления» в конце).

Заголовок задачи недели (`periodTitle('week', ...)`) показывает полную дату начала, если неделя пересекает границу месяца или года; например, «53 неделя, 28.12.2026–03.01.2027».

| `PlanYearCalendar` | `app/components/Plan/YearCalendar.vue` | выбор периода по календарю года: 12 месяцев (4 × 3) с днями, номер недели слева мелко и серым; пустые клетки первой и последней недели — бледные дни соседних месяцев (только подпись: не выбираются и не подсвечиваются, день выбирается в своём месяце). Режим `day` / `week` / `month`: при наведении подсвечивается день, неделя (на стыке месяцев — в обоих) или месяц целиком; точка «•» — в периоде есть задачи; текущий период — нежирная рамка. Наведение — светло-серый фон (как у кнопок панели редактора), выбор (нажатие, фокус с клавиатуры) — рамка без смены цвета (как у «Выполнено / Частично»). Разметка во всех режимах одна — при переходе Месяц / Неделя / День календарь не сдвигается. Неделя принадлежит году своего четверга, как её номер по ISO. Стрелки и Enter — с клавиатуры |
| `HeaderLink` | `app/components/HeaderLink.vue` | текстовая ссылка для слотов `Header` (`to`, `label`, `icon`): без рамки, подчёркивание при наведении |

Правило: каждая страница — `<Page>`; заголовок — `<Header>` в `#header`; фильтры и поиск — в `#toolbar`.
Ссылки в шапке — через слоты `Header` и `HeaderLink` (не кнопки — в шапке они громоздки): переходы в служебные
разделы (например, «Архив · N») — в `#right`; возврат на рабочее место («← Цели») — в `#left`.
Свою разметку `flex justify-between` вокруг `Header` не делать. Поиск в `#toolbar` — прижат вправо.
Большие окна (например, окно цели) — тоже `<Page>` внутри `UModal` с прозрачным `content`.

## 3. Формы

- Поля — **стандартные** `UInput`, `UTextarea`, `USelect`, `UInputNumber`, `UCheckbox`, `USwitch`
  в `UFormField` (подпись, `required`, `hint`, `error`). Их вид задан в `app/app.config.ts` через утилиту
  `field-base`: белый фон, `rounded-xs`, рамка `ring-accented`, высота 36 px. Свои стили полям не задавать.
- Многострочные поля, которые растут по высоте: `UTextarea` + подгонка высоты по `textareaRef`
  (пример — `fit()` в `app/components/Goal/Modal.vue`). Кандидат на общий компонент (см. ниже).
- Кнопки формы — `FormActions` (`isDirty`, `saving`, `disabled`, `closeTo`; события `save`, `reset`, `close`):
  без изменений — «Закрыть», с изменениями — «Отмена / Сохранить». Ширина 130 px.
- Одна форма на создание и правку. `useEditableForm` — загрузка, сравнение, сохранение, ошибки zod.
- Списки с поиском и страницами — `useCrudList(endpoint, {filters})`; на сервере — `defineCrud`.

## 4. Кнопки и переключатели

- `UButton` — по умолчанию `neutral / solid / lg` (36 px), `rounded-xs` (настроено в `app.config.ts`).
  Значок без текста — `variant="ghost"` или `outline`.
- Меню-пункты слева — только через `SideMenu` (внутри — утилиты `btn-menu`, `btn-menu-active`).
- Сегментные переключатели — утилита `plan-scope` + `nav-tab-active` у выбранного. Периоды плана и «Список / План» —
  не в шапке, а в боковом меню раздела (`PlanSectionMenu`).
- `DaySlotPicker` — выбор времени дня «Утро / День / Вечер»: квадратные значки восход / солнце / закат в стиле ✓ ½
  (`PlanStatusIcons`), подпись и часы — в подсказке. Часы — в настройках уведомлений. Для всех напоминаний «в какое время дня».
- Чипы и переключатели в читалке — `reader-chip(-active)`, `reader-toggle(-active)`.

## 5. Списки задач и этапов (План, Цели)

**`InlineTitle`** (`app/components/InlineTitle.vue`) — название, которое правится прямо в строке: клик по названию
(курсор — по месту клика) или F2 / Enter на строке (`start()`); Enter или клик мимо — сохранить (`save`), Esc — отменить,
Tab / Shift+Tab — сохранить и `tab` (±1). Пустое и неизменённое не сохраняется; новое название видно сразу.
Так же во всех списках: задачи, этапы, цели. Если у записи есть своё окно (цель), оно открывается не кликом по строке,
а отдельным входом: у цели — кнопка-прогресс (при наведении — «изменить») или ⋮ → «Открыть».

**`StatusList`** (`app/components/StatusList.vue`) — стандартный список со статусами для задач плана и этапов цели:
поле «Новая … — Enter» сверху (слот `#tools` справа от него — например, «Удалённые»), области «Не выполнено / Частично /
Выполнено» (свёртка «Выполнено» — кука `collapseKey`), перетаскивание за ⋮⋮ (в другую область — смена статуса), сквозной
номер, ✓ ½, меню ⋮ (слот `#menu`). **Название правится прямо в строке** (`InlineTitle`, режим text): клик по названию (или Enter / F2 на выбранной строке)
→ поле поверх названия; Enter или клик мимо — сохранить, Esc — отменить, Tab / Shift+Tab — сохранить и править соседнее;
пустое не сохраняется. События: `add`, `rename`, `status`, `reorder`; сохраняет страница. Отдельных форм для задачи и
этапа нет (у плана недели название тоже правится прямо в карточке, см. 5а).

- Области «Не выполнено / Частично / Выполнено» — `USeparator` с подписью `«Статус · N»`,
  «Выполнено» сворачивается (кука).
- Статус — `PlanStatusIcons` (✓ ½), размеры `md` / `sm`.
- Строка: ⋮⋮ (перетаскивание, `useSortable` с `forceFallback`), номер, вертикальный `USeparator`, название,
  значки, срок, ✓ ½, меню ⋮. Номер — сквозной по всем областям (`w-3 text-right tabular-nums`); так же в списке целей. Значков перед названием нет.
- **В строках списков — только название** (у целей — ещё срок и прогресс). У задач и этапов нет описания,
  комментария и (у этапов) срока — только название; подсказка при наведении — только если название не помещается.
  Описание и срок — только у цели.
- **Удаление — только в меню ⋮**, последним пунктом отдельной группой («Удалить»); отдельных кнопок «Удалить» в строках
  и окнах нет.
- Быстрое добавление — `UInput` с `icon="i-lucide-plus"` над списком (Enter — добавить, Esc — очистить).
- **Удаление — в «Удалённые»** (задачи плана, цели, этапы): `useSoftDelete(kind, onChanged)` — объект получает
  признак `deletedAt`, сообщение с «Отменить» (5 с) снимает признак. Уведомления удаляются по-прежнему (своя отмена
  на странице «Уведомления»).
- **`TrashButton`** (`kind`, `goalId?`, `popover?`) — значок «Удалённые» (`i-lucide-replace`, не корзина — корзина
  читается как «удалить») со счётчиком в стандартном месте: справа в шапке
  страницы (`Header #right`, у плана — правая часть шапки), в окне цели — у списка этапов. Нет удалённых — нет значка.
  Открывает **`TrashList`**: поиск, «Выбрать все», имя, откуда, когда удалено, сколько дней до автоочистки,
  «Восстановить · N» и «Удалить навсегда» (подтверждение в самом списке). На странице — в `UModal`, внутри окна — в
  `UPopover` (`popover`), окно поверх окна не открываем. Ссылка `?trash=<kind>` открывает список сразу.
- Прогресс — `GoalProgress`; срок — `GoalDue` (показ: сколько осталось «6 м. 3 д.» / «сегодня» / «просрочено 2 д.», дата — в подсказке; у выполненного — дата) и `GoalDueField` (галочка + дата + колокольчик напоминания:
  «По общим / Своё» — своё «за N дней» и время в день срока, на `DaySlotPicker`).

## 5а. План недели (`PlanWeekGrid`)

- **Только время начала.** День — ячейки по 15 минут (`shared/utils/planWeek.ts`: `PLAN_SLOT_MIN`,
  `PLAN_SLOT_PX` = 28 px, час — 112 px). В ячейке одна задача.
- **Карточка — сплошной блок на 30 минут**, две строки текста 12 px: «время название». Если через 15 минут стоит
  следующая задача — карточка сжимается до 15 минут (одна строка). Значков нет: выполненная — бледная, «Частично» —
  бледная левая половина и пунктир посередине. ⋮ — при наведении на правый верхний угол. Не помещающееся название
  раскрывается при наведении через 0,4 с — поверх соседних, с тенью.
- Наведение на пустую ячейку — подсветка и линия с временем; клик — новая карточка на это время с полем названия.
- **Перетаскивание** меняет день и время: задача, стоявшая в ячейке, и следующие за ней сдвигаются на 15 минут вниз до
  первой свободной ячейки (видно сразу, пока тянем). Не хватает места до конца дня — не переносится. Esc — отменить.
  **С Ctrl — копия**: исходная задача остаётся, копия встаёт по тем же правилам (Ctrl можно нажать и во время перетаскивания).
  Раскладку считают `layoutDay` / `placeInSlot` — одни и те же на странице и на сервере (`POST /api/plan/:id/place`).
- Копирование на дату — то же время, если занято — первая свободная ячейка после него (чужие задачи не сдвигаются).
- Меню ⋮ задачи (`PlanTaskMenu week`): «Выполнено», «Частично» (повторно — снять) | «Копировать на дату…» | «Удалить».
- **Окна задачи нет — название правится прямо в карточке** (окно уводило взгляд в середину экрана): клик по карточке
  (Enter / F2 на выбранной) — поле на месте названия, карточка раскрывается по тексту; Enter или клик мимо — сохранить,
  Esc — отменить; пустое не сохраняется (новая задача не создаётся). Статус, копирование, удаление — ⋮.
- Старые задачи (время не по 15 минут, длительность, несколько на одно время) показываются по ячейкам: время
  округляется вниз, совпадения — цепочкой вниз. В базу время записывается, когда в этом дне что-то ставят или
  переносят. Длительность (`endMin`) в базе остаётся, но не показывается.

## 6. Окна, сообщения, подсказки

- Окна — `UModal`. Окно поверх окна не делаем; правка вложенного — раскрытием в списке.
- Несохранённые изменения — автосохранение при сворачивании или плашка внутри формы, не `window.confirm`.
- Сообщения — `useToast()`: ошибки `color: 'error'`, удаление с отменой — `color: 'warning'` + действие «Отменить».
- Подсказки — `UTooltip`; внутри окон задавать `content` с `z-[100]`, светлая карточка
  (`bg-white/95 ring ring-default shadow-lg rounded-sm`).

## 7. Иконки и цвета

- Иконки — `i-lucide-*`.
- Цвета — токены темы: `text-highlighted / default / toned / dimmed`, `bg-elevated`, `ring-default / accented / inverted`,
  `text-warning` (скоро срок, изменения), `text-error` (просрочено, ошибка), `text-success`.

## Кандидаты в общие блоки (вынести при унификации)

- `AutoTextarea` — `UTextarea`, растущий по высоте (сейчас подгонка повторяется в нескольких файлах).
- `StatusArea` — разделитель области со счётчиком и сворачиванием (повторяется в плане, итогах, целях).
- `QuickAdd` — поле быстрого добавления.
- `IconToggle` — квадратный значок-переключатель с рамкой (действия в итогах).
- `TextTabs` — вкладки-ссылки (итоги недели) и `SegmentTabs` (на `plan-scope`).

## Известные отступления (задачи унификации)

- `PlanReviewPanel` и `NotificationBell` / страница уведомлений используют собственную разметку карточек.
- Самодельные `textarea` в `PlanReviewPanel` — перевести на общий растущий `UTextarea`.
- `PageCanvas` не используется — решить, нужен ли.
- Страницы «Статьи», «Пользователи», «Обои» ставят кнопки рядом с `Header` своей разметкой — перевести на слоты `#left` / `#right`.
